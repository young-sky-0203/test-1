# license-demo：数值统计示例

这是一个开源许可证实践用的小型 Python 代码库。输入一组有限数值，输出数量、最小值、最大值、平均值和中位数。只使用 Python 标准库，无需安装第三方依赖。

## 运行方法

安装 Python 3，在本目录执行：

```sh
python stats.py 60 75 90 100
```

输出：

```text
count: 4
min: 60
max: 100
mean: 81.25
median: 82.5
```

程序接受负数和小数；未提供参数、非数字参数或非有限值会产生错误提示。
